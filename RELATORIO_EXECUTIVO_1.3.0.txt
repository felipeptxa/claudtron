1. SUMARIO EXECUTIVO
--------------------------------------------------------------------------------
A versao 1.3.0 do Cloudtron OneClick transforma o aplicativo em um Hub de
Inferencia Multi-Provedor com Failover Automático Resiliente, eliminando a
dependencia de um unico provedor de IA. Principais entregas:

  1. Correcao do bug visual das abas nas Configuracoes - as abas inativas
     agora exibem estritamente fundo #0b1329, borda cinza escura e texto
     cinza, enquanto a aba ativa exibe fundo azul ciano com brilho.
  2. Reestruturacao completa da aba "Provedores & API Keys" - substituicao
     do dropdown simplista por cards independentes para cada provedor
     (NVIDIA NIM, Groq Cloud, OpenRouter, Google AI Studio, DeepSeek,
     Anthropic Claude), organizados por Tier (1: Gratuitos & Alta Potencia;
     2 & 3: Modelos Avancados / Pay-as-you-go).
  3. Restauracao do selo rico do NeMo com nota e popover detalhado de
     auditoria (diagnostico de sintanca, verificacao de seguranca,
     latencia da avaliacao).
  4. Correcao da linha de telemetria para nao misturar Modelo com Modo -
     agora exibe [Modelo] · [Hora] • ⚡ TTFT: [X]s | Total: [Y]s •
     Mode: [Plan / Build] • Effort: [Esforço] • [Badge NeMo].
  5. Suporte a salvar múltiplas chaves de API no localStorage para a
     Fila de Swap/Failover no backend.

3. MATRIZ DE FAILOVER VALIDADA ENTRE PROVEDORES
--------------------------------------------------------------------------------
A fila de swap/failover foi implementada no backend (server.js) com a
seguinte ordem de prioridade:

| Ordem | Provedor          | Endpoint                                          | Chave de Ambiente      | Modelo Default              |
|-------|-------------------|---------------------------------------------------|------------------------|-----------------------------|
| 1     | NVIDIA NIM        | https://integrate.api.nvidia.com/v1/chat/completions | NVIDIA_API_KEY         | nemotron-3.5-super-vl-120b  |
| 2     | Groq Cloud        | https://api.groq.com/openai/v1/chat/completions   | GROQ_API_KEY           | deepseek-r1-distill-llama-70b |
| 3     | OpenRouter Free   | https://openrouter.ai/api/v1/chat/completions     | OPENROUTER_API_KEY     | deepseek/deepseek-r1-...:free |
| 4     | DeepSeek Oficial  | https://api.deepseek.com/chat/completions         | DEEPSEEK_API_KEY       | deepseek-chat               |
| 5     | Google AI Studio  | https://generativelanguage.googleapis.com/...     | GOOGLE_API_KEY         | gemini-1.5-pro              |
| 6     | Anthropic Claude  | https://api.anthropic.com/v1/messages             | ANTHROPIC_API_KEY      | claude-3-7-sonnet-20250219  |

Comportamento de Failover:
- Se o provedor ativo retornar HTTP 429 (Rate Limit), 402 (Payment/Quota
  Exceeded) ou 401 (Chave Invalida), ou ocorrer timeout > 15s, o backend
  NAO aborta a comunicacao SSE.
- O backend envia evento SSE de failover ao cliente:
  event: failover
  data: { "from": "NVIDIA NIM", "to": "Groq Cloud", "reason": "Rate Limit (429)" }
- Executa imediatamente a chamada ao proximo provedor valido da fila com
  o mesmo historico de mensagens.
- Se o erro ocorrer apos tokens ja transmitidos, o buffer parcial e
  limpo para o modelo substituto responder de forma coesa.

As chaves sao configuradas no modal de Configuracoes > Provedores & API
Keys e salvas no localStorage como:
  cloudtron_keys: { nvidia: "...", groq: "...", openrouter: "...",
                    google: "...", deepseek: "...", anthropic: "..." }
