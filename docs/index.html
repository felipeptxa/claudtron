Perguntas Frequentes

Respostas diretas sobre arquitetura, requisitos de hardware, custos e privacidade no CLAUTRON OneClick.

Preciso de GPU dedicada ou placa NVIDIA local?

Não. O processamento pesado dos 120 bilhões de parâmetros ocorre nos nós de alta densidade do NVIDIA NIM na nuvem. Seu PC só precisa rodar a interface Electron com fluidez no Windows 10/11.

Como obtenho minha chave de API (nvapi-...)?

Basta criar uma conta gratuita no portal build.nvidia.com e acessar a página do modelo Nemotron 3.5 Super VL. A NVIDIA oferece créditos generosos para desenvolvedores testarem os modelos.

Meus dados e conversas são salvos onde?

Seu histórico de conversas e configurações ficam salvos 100% localmente no seu computador (em JSONL criptografado localmente). Nada é enviado para servidores de terceiros além da inferência oficial da NVIDIA.

Posso auditar e contribuir com o código?

Com certeza! O projeto é 100% de código aberto sob licença MIT. Você pode clonar o repositório no GitHub, criar pull requests, sugerir melhorias e reportar bugs na aba de Issues.
