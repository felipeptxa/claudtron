1. SUMARIO EXECUTIVO
--------------------------------------------------------------------------------
A versao 1.2.3 do Cloudtron OneClick e uma atualizacao crítica de estabilidade
e experiencia de uso (UI/UX), focada em eliminar falhas de streaming SSE,
atualizar endpoints EOL (fim de vida), corrigir inconsistencias visuais e
resolver o erro 404 de download na landing page.

Os principais pilares entregues foram:

  1. Correcao crítica de streaming SSE e buffer de linha resiliente
     - Eliminado o erro "Unterminated string in JSON" ao enviar prompts longos
       com quebras de linha, aspas e blocos de codigo.
     - Buffer acumulador com lines.pop() reteve fragmentos de linha incompletos
       ate o próximo chunk de rede, impedindo JSON.parse prematuro.
     - Parsing envolvido em try/catch resiliente que nunca derruba a comunicacao.

  2. Atualizacao oficial da versao v1.2.3
     - package.json, package-lock.json, app.html, docs/app.html,
       index.html, docs/index.html, server.js, main.js, readme.md e
       test/suite.js atualizados para 1.2.3.
     - Build NSIS gerado e publicado na release v1.2.3 do GitHub.

  3. Limpeza visual e ergonomia do App Desktop
     - Removidos os 3 pontos estilo Mac da topbar da janela.
     - Removido o seletor de modelo da barra superior; mantido apenas branding
       "Cloudtron OneClick v1.2.3" e LED verde (7px glow) de status NVIDIA.
     - Aba Live Preview corrigida: texto "▷ Live Preview" (sem duplicacao),
       container do sandbox com display:none por padrão.
     - Seletor Unificado de Inteligência na caixa de prompt: unico botao em
       pilula (#0d1424, borda ciano sutil) com dropdown para cima contendo
       Modelos NVIDIA NIM e Lentes de Contexto & Esforço.
     - Endpoint EOL removido: qwen/qwen2.5-coder-32b-instruct.
     - Nova secao "OTIMIZACAO & AGENTES" nas Configuracoes com toggle
       NVIDIA NeMo Guardrails & Evaluator (On/Off).

  4. Landing page e correcao do download 404
     - Botao principal aponta diretamente para o binario v1.2.3 compilado.
     - Link secundario para releases/latest como fallback.
     - Atributos target="_blank" rel="noopener noreferrer".
     - Mockup da landing sincronizado com as mudancas visuais do app.

  5. Validacao, testes e build automatizado
     - npm test: 19/19 testes passando.
     - npm run dist: instalador executavel NSIS gerado com sucesso.
     - Release/tag v1.2.3 criada com binario e latest.yml.


2. MUDANCAS TECNICAS DETALHADAS
--------------------------------------------------------------------------------
2.1 Correcao do Payload JSON e SSE Buffer (@app.html e @server.js)
  - Frontend: fetch('/api/messages') usa exclusivamente JSON.stringify({ ... }),
    sem concatenacao manual de strings.
  - Frontend: leitor de streaming SSE implementa buffer acumulador:
    buffer += decoder.decode(value, { stream: true });
    lines = buffer.split('\n'); buffer = lines.pop() || '';
    Isso retem fragmentos de linha incompletos ate o próximo chunk.
  - JSON.parse envolto em try/catch resiliente; fragmentos invalidos sao
    ignorados silenciosamente, erros reais do proxy sao propagados.
  - Proxy: cabeçalhos SSE corretos (text/event-stream, no-cache,
    keep-alive) e chunks repassados com res.write(chunk).

2.2 Limpeza de Residuos no Instalador (@package.json)
  - build.nsis.deleteAppDataOnUninstall: true -> desinstalador limpa
    automaticamente a pasta %APPDATA% (API keys, sessoes antigas, caches).
  - build.nsis.differentialPackage: false -> pacote completo, nao diferencial.

2.3 Sanitizacao de Inicializacao (@app.html)
  - Validacao no carregamento inicial: se JSON de sessoes ou configuracoes
    no localStorage estiver corrompido, a chave afetada eh limpa com fallback
    para padroes, evitando propagacao de payload quebrado.

2.4 Modelo EOL Removido
  - qwen/qwen2.5-coder-32b-instruct removido do catalogo de modelos.
  - Substituido por deepseek-ai/deepseek-v4.1-flash (Cloudtron Coder).

2.5 Novos Modelos NVIDIA NIM no Seletor Unificado
  - Cloudtron Omni: nvidia/nemotron-3.5-super-vl-120b-a12b
  - Cloudtron Coder: deepseek-ai/deepseek-v4.1-flash
  - Cloudtron Logica: deepseek-ai/deepseek-r1
  - Cloudtron Redator: meta/llama-3.3-70b-instruct

2.6 Lentes de Contexto & Esforço
  - Engenharia & Codigo: temp 0.20, top_p 0.90, 8192 tokens, thinking ativo
  - Raciocínio Profundo: temp 0.60, top_p 0.95, 8192 tokens, thinking ativo
  - Criativo & Exploracao: temp 1.05, top_p 0.98, 4096 tokens, thinking inativo
  - Rapido & Direto: temp 0.30, top_p 0.85, 2048 tokens, thinking inativo
